# Experiment 4 – Interactive Post Scheduler

## Aim
To design and implement an interactive calendar interface for scheduling and managing posts, while optimizing rendering performance and implementing testing strategies.

## Objectives
- Implement a calendar-based scheduling interface.
- Display social media posts on specific dates.
- Enable drag-and-drop rescheduling.
- Use React memoization techniques to reduce unnecessary renders.
- Implement automated testing for UI components.

## Technologies Used
- React.js
- FullCalendar
- JavaScript
- Vitest
- React Testing Library
- Vite

## Features
- Interactive monthly calendar
- Scheduled social media posts
- Drag-and-drop rescheduling
- Post statistics
- Memoized components using `memo`
- `useMemo` and `useCallback` for performance optimization
- Automated component tests

## Expected Outcome
A functional, optimized, and testable calendar-based social media scheduling application.
